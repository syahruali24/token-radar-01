03 / HOW TO READ THIS

Methodology & limits

Every estimate is derived from one frozen protocol snapshot.

01 — VALUE MODEL

One model, every row.

base = TVL × —
growth_pct = clamp(7d change, −60, 120)
growth multiplier = 1 + (growth_pct ÷ 100) × 0.5
maturity multiplier = 0.6 + min(age, 1,095) ÷ 1,095 × 0.4
implied value = clamp(round(base × growth multiplier × maturity multiplier), $1, $100T)

Market multiple calculated from token-bearing snapshot records.

02 — CANDIDATE RULE

Filter the noise.

Pre-token records require null market cap, CoinGecko ID and symbol. Candidate names exclude version markers, wrapped or staked products, and exchange-led products. Excluded categories include CEX, Bridge, Canonical Bridge, Liquid Staking, Liquid Restaking and Restaked BTC.

Snapshot record only · no future token claims
