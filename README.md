A snapshot-driven token launch radar with a market multiple computed from the frozen data, a strict candidate rule that excludes wrapped, staked, bridged and exchange-led products, and a ranked board with an individually costed farm plan for every protocol. The row count is computed from the snapshot and candidate rule at runtime.
